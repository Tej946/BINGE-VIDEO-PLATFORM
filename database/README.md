# Database Directory

This folder holds database migrations, SQL schemas, and seed data.

## Files
- `schema.sql`: Baseline schema containing Users, Videos, Comments, Video Reactions, and Subscriptions.

## Migrations / Seeding
Depending on your ORM or migration tool (e.g. Prisma, Knex, Drizzle, SQLAlchemy, Alembic, or raw SQL):
- Store migration files in `migrations/`
- Store initial test data or seeds in `seeds/`
